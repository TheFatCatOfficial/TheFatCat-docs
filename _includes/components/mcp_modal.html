连接 TheFatCat 文档知识库 (MCP) Connect TheFatCat Docs with MCP

通过 Model Context Protocol (MCP)，您可以让 Cursor、Claude Desktop、Claude Code 等本地智能体直接检索和读取 TheFatCat 官方协议文档。

Connect TheFatCat documentation to Cursor, Claude Desktop, Claude Code, or VSCode via Model Context Protocol (MCP).

📖 官方文档发布站 📖 Official Docs Site https://thefatcatofficial.github.io/TheFatCat-docs/ ↗
🐙 官方文档仓库 🐙 Official Docs Repo https://github.com/TheFatCatOfficial/TheFatCat-docs ↗
claude_desktop_config.json / cursor mcp.json 
{
  "mcpServers": {
    "thefatcat-docs": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-fetch",
        "--allowed-origins",
        "https://thefatcatofficial.github.io"
      ]
    }
  }
}
Claude Code / Terminal CLI 
claude mcp add thefatcat-docs -- npx -y @modelcontextprotocol/server-fetch --allowed-origins https://thefatcatofficial.github.io
