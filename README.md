# TheFatCat public documentation

This repository contains the public, reviewable documentation for TheFatCat.
The private product repository, deployment configuration, internal plans and
operational material are intentionally kept separate.

Read the published documentation at
[thefatcatofficial.github.io/TheFatCat-docs](https://thefatcatofficial.github.io/TheFatCat-docs/).

## Publishing

Every push to `main` runs the included GitHub Pages workflow. Pages must use
**GitHub Actions** as its publishing source.

## Editing

Pages are Markdown files. Their front matter controls the title, ordering and
parent section shown in the left navigation. Do not publish contract addresses
until they have been deployed and independently verified.
