# 安全托管常见问题

## 1. 如果官方网站离线，怎么办？

本金保存在质押合约中，不由网站保管。核对官方部署地址与验证源码后，可按[紧急退出说明]({% link zh/guides/emergency-exit.md %})通过兼容的钱包或区块链浏览器直接赎回本金、领取已结算奖励。

## 2. 紧急暂停会冻结本金吗？

普通本金赎回不受协议暂停限制，也不需要维护者批准。仓位核验、账本处理及 FATCAT 转账仍须成功。退出会放弃当前开放餐次的份额，历史奖励权益仍然保留。

## 3. 管理员能提走协议资金吗？

核心本金和奖励合约没有管理员扫仓或救援提款入口。但上游税收收益存在不同的权限：收入金库在永久锁定前可以升级，部分上游收入可以在紧急情况下由 Flap 的授权角色转移。这些收入不是用户质押的 FATCAT 本金，相关变化仍可能影响奖励来源。

上游代操作服务也可能因升级而改变行为。普通赎回和奖励领取仍付给仓位所有者；新增质押仍需要用户余额和有效授权。详见[托管与记账边界]({% link zh/safety/custody.md %})。

## 4. 应急措施会怎样影响使用？

异常期间，协议可暂停部分操作、限制受影响资产或调整执行条件。这可能延后新质押、奖励采购及结算；已完成的交易不会因此撤销，恢复也不保证即时完成。

部分待采购奖励可能改以 WBNB 结算。用户的资历、历史权益及实际可领取金额，应以仓位记录和已完成结算为准。上游平台的权限与项目自身的应急权限分别存在，详见[风险披露与运行条件]({% link zh/safety/risks-and-status.md %})。
