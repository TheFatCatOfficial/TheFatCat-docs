# 核算约束

这些规则说明本金和奖励如何分别记录，以及分配与出金受到哪些约束。它们不保证任意代币行为、资产市值或链中断情况下的安全。

## 本金托管

本金金库应保留与登记未退出本金相对应的 FATCAT。奖励采购与本金金库分开，普通本金赎回不受协议暂停限制；成功提款仍取决于链和代币转账正常完成。详见[托管边界]({% link zh/safety/custody.md %})。

## 分配与出金

新一餐预算按 Belly 已确认储备扣除现有预留资金后计算，单次最多计入 16 小时。处于奖励期、准时推进的八小时餐次，最多分配这部分未预留资金的 1/21。

实际出金额度采用另一个基数：**八小时支出窗口开启时的 WBNB 总余额**，包含待结算份额已预留的资金。初始额度为该余额的 16/168，窗口内新增入金不提高当窗额度。分配限额和出金限额分别生效。详见[Belly 规则]({% link zh/protocol/belly.md %})。

## 推进与交易成本

餐次推进不需要逐个处理所有质押者，但仍须处理菜单中的相关资产。菜单规模和具体操作会影响 Gas，因此不能理解为每笔交易都具有固定成本。

## 已结算奖励与取整

在有效记账和受支持代币行为下，一批奖励的总领取量不应超过该批实际收到的资金。向下取整可能留下少量残差，这些残差保留在奖励分配环节。

已结算未领取的奖励仍须保留对应资金。尚待采购的预算也不能因用户未领取就被当作空闲余额；只有确认不存在合资格领取者的份额，才能按规则解除预留。详见[托管边界]({% link zh/safety/custody.md %})和[采购结算]({% link zh/protocol/execution.md %})。
