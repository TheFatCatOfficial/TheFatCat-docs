# 术语对照

Belly、餐次和食谱是协议面向社区使用的表达。下表说明它们在实际使用中的含义：

| 产品词汇 | 对应含义 | 使用时需要了解 |
|:---|:---|:---|
| **The Belly（大肚皮）** | 奖励储备金库 | 接收奖励收入，逐餐分配；与质押本金分开，实际流出受窗口额度限制。 |
| **Meal（餐次）** | 奖励记账周期 | 推进间隔至少八小时；完成一餐后记录份额，奖励仍须后续结算。 |
| **Diet（食谱）** | 仓位选择的奖励资产 | 可从启用菜单中选择；切换不重置资历，下一餐生效，旧奖励仍可领取。 |
| **Seniority（时间资历阶梯）** | 仓位参与时间形成的时间资历系数 | 生效后从 1 档逐餐升至 22 档；是分配权重，不是收益承诺。 |
| **满级** | 资历达到 22 档 | 后续参与保持上限，不继续提高时间资历系数；奖励仍受收入和全体权重影响。 |
| **Forfeit（份额放弃）** | 退出时放弃当前开放餐次的份额 | 不抹去此前已赚取奖励，也不收取本金退出费。 |
| **Belly 流出限额** | 八小时窗口内可释放的奖励资金上限 | 初始为窗口开启时 WBNB 总余额的 16/168，约 9.5238%；已结算奖励领取不消耗此额度。 |
| **FEED** | 公众参与的协议维护 | 尝试兑换收入、推进到期餐次及处理指定批次；仅符合条件的成功兑换产生推动奖励。 |
