# 安全性与治理

说明资金托管边界、记账检查、监控措施与运行风险。

## 安全索引

- **[托管与记账边界]({% link zh/safety/custody.md %})**：本金隔离、核心合约无管理员扫仓接口，以及有条件的取整界限。
- **[测试与验证]({% link zh/safety/audits-and-hardening.md %})**：当前记账保护与内部回归、不变量测试的覆盖范围。
- **[运行监控]({% link zh/safety/monitoring.md %})**：监控与应急处置措施概述，以及用户应对入口。
- **[风险披露与运行条件]({% link zh/safety/risks-and-status.md %})**：开放规则、外部依赖与结算延迟。
