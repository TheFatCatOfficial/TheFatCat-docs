# 原则与限制

| 原则 | 机制 | 边界 |
|:---|:---|:---|
| 从实际收入中分配 | Belly 保留计价资金，新餐次预算扣除已有保留资金。 | 不承诺固定 APY、APR 或最低奖励；储备不能替代缺失的收入。 |
| 本金与奖励采购分开 | 本金留在质押金库，普通赎回不检查暂停标记。 | 链可用性、交易执行及代币行为仍会影响操作。 |
| 允许资产选择 | 每个仓位独立选择启用的菜单资产。 | 上市不保证代币价值、发行方履约或兑换成功。 |
| 将时长纳入权重 | 本金线性计权，普通资历从 1× 升至 22×。 | 开仓、退出及食谱变化会改变份额比例。 |
| 限制分配与支出 | 控制器分配和 Belly 出金分别有额度约束。 | 暂停、待结算餐次和市场条件可能延迟结算。 |
