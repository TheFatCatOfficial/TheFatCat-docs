# 分配设计选择

TheFatCat 通过三项机制组织交易税收入：

| 设计问题 | 选择 | 限制 |
|:---|:---|:---|
| 如何分配不均匀的收入？ | 计价资金先保留在 Belly，每餐按未保留资金的一定比例分配。 | 储备把已有收入分配到不同餐次，不创造收入，也不保证分红稳定。 |
| 用户领取什么资产？ | 每个仓位选择启用的菜单资产，采购与分配分开。 | 结算依赖资产资格、流动性、预言机检查及回退条件。 |
| 时长如何影响份额？ | 本金乘以资历系数，普通持续在席仓位从 1× 升至 22×。 | 新资金仍会降低已有参与者的份额比例，时长不能固定奖励金额。 |

普通新仓从下一餐开始参与。退出与更换食谱按明确的餐次边界处理，不让新仓立即领取开仓餐次的分配。

公式及条件见 [Belly 分配]({% link zh/protocol/belly.md %})、[餐次与资历]({% link zh/protocol/meals-and-seniority.md %})和[执行]({% link zh/protocol/execution.md %})。
