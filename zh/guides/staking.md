# 质押与仓位生命周期管理

全面指导如何在 TheFatCat 中开启质押仓位、管理独立仓位，以及攀登 22 档资历阶梯。

---

## 1. 参与前提与最低门槛

在 TheFatCat 的 [`StakingVault`]({% link zh/contracts.md %}) 中开立质押仓位需满足以下前提：

- **最低本金门槛**：**100,000 FATCAT**（严格占代币总供应量 1,000,000,000 的 0.01%）。
- **代币授权（Approve）**：需先授权 `StakingVault` 合约划转您的 FATCAT 代币。
- **Gas 储备**：钱包中需留有极少量的原生 BNB 作为 BNB Chain 上的交互 Gas 费。

{: .note }
100,000 FATCAT 的开仓门槛是合约构造函数中固化的不可篡改参数。它充当天然的防粉尘攻击防线，确保全网状态树维持在极高 Gas 效率状态。

---

## 2. 如何通过官网开启质押

1. 使用主流 Web3 钱包（如 MetaMask、Binance Web3 钱包、OKX 钱包、Trust Wallet 或 WalletConnect）访问官网 [thefatcat.fun](https://thefatcat.fun) 并连接钱包。
2. 输入您希望质押的 FATCAT 数量（必须 $\ge 100{,}000$）。
3. 选择您期望的初始分红代币（**食谱 Diet**，默认为原生 BNB）。
4. 点击 **Approve** 并在钱包中确认代币授权。
5. 点击 **Stake** 并确认交易，质押成功。

*(注：对于希望在官方前端离线时直接通过 BscScan 浏览器交互的资深用户，可参考 [紧急退出与底层交互指南]({% link zh/guides/emergency-exit.md %})。)*

## 3. 仓位生效与激活生命周期

质押并不会追溯享有当前正在进行的餐次收益：

```
当前时刻 T_now ─────────────► 当前餐次推进 (advance) ──────────► 下一餐次推进
[ 用户调用 stake() ]           [ 仓位正式激活 (j_i = m+1) ]        [ 产生首期收益 ]
(当前餐次 m: 有效权重 = 0)     (资历 = 1 档, 权重 = p_i × 1)       (资历晋升为 2 档)
```

1. **待生效餐次（餐次 $m$）**：若在餐次 $m$ 期间质押，本金会即刻记入金库安全托管，但在当前活跃餐次中的有效权重为 0。
2. **正式生效（$j_i = m + 1$）**：当 Keeper 或任何用户触发 `advance()` 推进到下一餐次时，您的仓位正式以 **1 档资历（1× 权重）** 激活入席。
3. **阶梯式攀升**：此后每完整经历一个 8 小时活跃餐次，您的资历倍数自动加法递增 $+1$，直至达到满级 22 档封顶（需经历 21 次完整餐次，标准节奏下历时 7 天）。

{: .important }
**创世启动 7 天蓄水与爬坡期**：协议在刚发射上线时，分红释放受到不可篡改的 7 天物理墙钟闭锁（`LaunchIntervalController.MIN_REWARD_START_DELAY = 7 days`，即 `rewardStartAt = block.timestamp + 7 days`）。在此期间，时钟与餐次正常推进、资历正常按梯度攀升，但分红释放比例强制为 0；交易税持续汇入 The Belly“只进不出”，确保早期参与者在公平起跑线上建立起初始资历分布。

## 4. 多仓位独立管理

在 TheFatCat 中，每笔质押都会生成一个具备独立生命周期、资历时钟与分红食谱的隔离仓位：

- **追加本金**：如需追加质押 FATCAT，只需在质押界面开启一个新仓位即可。同一个钱包地址可以同时创建并持有多个互不影响的独立仓位。
- **差异化食谱自选**：同一钱包下的不同仓位可自由配置不同的分红资产（例如：仓位 #1 专注获取 BNB，仓位 #2 专注获取美股 bStocks）。
- **一键批量领取**：虽然各仓位的成熟进度各自独立，但官网管理看板支持在单个交易中跨全部仓位一键合并提取分红，最大限度为您节省 Gas。
- **资历凭据（ERC-721）**：用户在退出成熟仓位时，可选择销毁 100,000 FATCAT 铸造链上 [资历凭据 ERC-721]({% link zh/guides/seniority-certificates.md %})，作为永久忠诚纪念并支持未来新开仓位倍数继承。
