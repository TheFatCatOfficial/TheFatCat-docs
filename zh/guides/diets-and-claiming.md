# 食谱自选与收益提取指南

指导如何自主选择期望的分红代币（食谱 Diets）、在不同行情周期中切换分配，以及提取收益时的原生 BNB 自动解包功能。

---

## 1. 什么是食谱（Diet）？

在 TheFatCat 中，社区绝不被捆绑在单一静态的分红币种上。相反，每个质押仓位均可独立从协议认证的 [食谱菜单（MENU）]({% link zh/protocol/execution.md %}) 中自主指定期望的 **收益资产（Diet Asset）**：

- **BNB（网络规范原生资产）**：默认食谱与协议兜底清偿资产（链上底层以规范 WBNB 记账）。它完全不需要经过二级市场兑换，且承担零发行方与对手方信用风险。质押者提取时可直接获得原生 BNB，无需任何额外手动解包操作。
- **bStocks（第三方发行的代币化美股凭据）**：由第三方机构（如 Backed 等）发行的追踪传统美股或指数 ETF 价格表现的代币化凭据（并非直接持有标的底层股票的所有权或股东投票权，例如代币化英伟达、SpaceX、纳斯达克 100 或标普 500 追踪凭据）。**合规与受限地区提示**：代币化凭据的具体合规性及可提供范围严格取决于发行方具体发售条款，通常存在明确的投资者资格及受限司法管辖区（如美国、英国等地区居民受限）限制，参与者须按具体发行文件自担核验义务；该类资产受制于单餐 5% 的观察期配额上限（创世首发菜单标的享 7 天豁免）。
- **FATCAT（协议原生代币）**：在达成 AMM 毕业、流动性深厚稳定且完成 TWAP 预言机预热后，经治理评估开放加入菜单。
- **未来潜在入选资产（生态扩展）**：未来潜在可能经过时间锁治理流程批准上市的高流动性优质加密资产、主流蓝筹代币或合规稳定币。

{: .tip }
由于每次质押都会生成独立的仓位 ID，同一个钱包可以持有不同食谱的多个独立仓位（例如：仓位 #1 专注获取稳健 BNB，仓位 #2 专注获取代币化美股）。

---

## 2. 如何切换分红食谱

您可随时在官网管理面板中为您的仓位切换食谱：

1. 连接钱包并在 [thefatcat.fun](https://thefatcat.fun) 进入 **仓位管理（Positions）** 面板。
2. 找到您希望调整的仓位卡片，点击 **食谱（Diet）** 下拉菜单。
3. 从已认证的菜单中选择您心仪的新资产（如 BNB、bStocks 等）。
4. 点击 **Switch Diet（切换食谱）** 并在钱包中确认该笔交易。

### 切换食谱的核心规则：
1. **资历绝对零惩罚**：切换分红资产 **绝不会重置或扣减您的资历倍数**。您之前累积的资历档位（$c_i$）获得 100% 完整继承。
2. **下一餐次正式生效**：新食谱选择将在 **下一个餐次边界（$m + 1$）** 正式生效。当前正在进行的开放餐次仍按原资产计提。
3. **历史收益永久保留**：在旧食谱下已经累积但尚未领取的代币收益，将永久保存在您的提取列表中，绝不会丢失或被新资产覆盖。

---

## 3. 提取已结算收益

TheFatCat 中的分红收益 **永不过期**。它们会在各个餐次结算后持续累积，存放在非托管的分发器合约中，随时可供提取。

### 官网提取操作流程：

1. 在 [thefatcat.fun](https://thefatcat.fun) 打开 **收益概览（Rewards / Belly）** 页面。
2. 查阅您在各个仓位下已结算的收益余额（如 BNB、bStocks 等）。
3. **按仓位提取**：在指定仓位卡片上点击 **Claim（提取）**。为保障交易不会因历史批次过多而遭遇 Gas 耗尽，前端会自动带入本次结算的截止批次，安全完成收益到账。
4. 在连接的 Web3 钱包中确认交易即可。

### 原生 BNB 自动解包功能（Auto-Unwrap）
当您的食谱包含 BNB（链上底层以 WBNB 形式记账）时，合约提款逻辑会自动将资金解包为 **原生 BNB** 并直接打入您的钱包，无需用户额外手动执行解包（Unwrap）。

{: .tip }
**长期未领取的 Gas 安全保障**：若您数月未上线查看，仓位可能累积了大量历史执行批次。协议支持按批次分段提取（`claimThrough` / `claimNativeThrough`），确保即使面对长期积压，每次提取也能在标准区块 Gas 限额内顺利完成。

*(对于希望在前端脱网时直接在 BscScan 浏览器调用合约底层的资深用户，可查阅 [紧急退出与底层交互指南]({% link zh/guides/emergency-exit.md %})。)*
