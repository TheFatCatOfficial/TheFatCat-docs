# 代币发射与功能开放流程

TheFatCat 分三个阶段开放交易、质押和质押奖励。本页说明各阶段可以做什么，以及为什么先开放质押、再开放奖励。当前进度请查看 [Belly 页面](https://thefatcat.fun/belly)。

**代币发射 → 毕业后开放质押 → 七天积累期 → 开放质押奖励分配与领取**

## 三个开放阶段

| 阶段 | 开放时间 | 您可以做什么 | 质押奖励状态 |
| :--- | :--- | :--- | :--- |
| **第一阶段：代币发射** | 代币已上线，等待毕业 | 通过官方交易入口参与交易，查阅协议规则。已开放的收入维护入口独立运行。 | 暂未开放质押与质押奖励领取。 |
| **第二阶段：开放质押** | 计划在代币毕业后马上开放，以实际开放状态为准 | 质押 `$FATCAT`、选择奖励资产，并按规则管理或退出仓位。生效仓位可随成功推进的餐次积累时间资历。 | 全协议进入七天积累期，期间不分配新的质押奖励。 |
| **第三阶段：开放奖励** | 实际开放质押满七天，第八天起 | 继续质押和管理仓位，在奖励入口开放且结算完成后领取已结算奖励。 | 餐次推进可开始分配质押奖励；实际可领取金额仍取决于收入、采购与结算。 |

{: .important }
**七天从全协议实际开放质押时统一起算，并不是从 `$FATCAT` 发射时起算。** 七天期满后，奖励执行以链上为准。

## 为什么分阶段开放

### 先完成发射与毕业，再开放质押

第一阶段提供交易入口和协议说明，用户可以在质押开放前了解协议运行机制与参与方式。代币毕业后，按发布流程开放质押；具体是否已经开放，请以 Belly 页面的实际状态为准。

### 留出初始奖励资金的积累时间

开放质押后的七天用于积累初始奖励储备。成功处理的交易税收入可进入 Belly 蓄水池，为后续餐次分配提供资金。实际积累金额取决于收入与处理情况，不承诺固定收益或最低奖励。

### 时间资历与奖励分配分别计算

积累期内，普通新仓位仍从下一次成功推进的餐次生效，以 1× 时间资历系数起步。此后每完成一个有效餐次增加 1×，最高 22×，需晋升 21 次；推进延迟会延后晋升。

积累期内质押者资历正常增长，这会影响奖励开放后的相对权重；但积累期内不产生资产奖励。仓位权重 = 本金 × 时间资历系数 × 当前奖励资产的激励系数。

### 奖励开放后：先结算，再领取

第三阶段开放后，奖励依次经过餐次分配、采购或符合条件的 WBNB 回退、结算与领取。开启奖励不代表奖励代币会自动到账，需要自行领取。

{: .important }
**FEED 的推动奖励在七天积累期内正常结算**，参与条件见[FEED 机制与去中心化维护]({% link zh/guides/community-keeper.md %})。

## 常见问题

### 代币上线七天后就能领取质押奖励吗？

不能按代币上线时间计算。七天从全协议实际开放质押时开始；期满后，还需完成对应餐次的分配与结算，才会形成可领取奖励。

### 晚一些加入，还要重新等七天吗？

不会重新计算全协议积累期。不过，普通新仓位仍须从下一次成功推进的餐次生效，时间资历也按该仓位自己的进度增长，不追溯参与之前的餐次。

### 第三阶段开放，就会立刻收到奖励吗？

奖励不会自动到账。请在 Belly 页面查看仓位与已结算奖励，按页面提示领取；待采购或待结算的奖励需要继续等待相应处理完成。

准备参与时，请阅读[质押与仓位]({% link zh/guides/staking.md %})和[食谱与领取]({% link zh/guides/diets-and-claiming.md %})，或前往 [Belly 页面](https://thefatcat.fun/belly)查看当前开放进度。
