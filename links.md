## Anti-Phishing Security Checklist

Before interacting with any protocol application or contract:

1. **Verify Exact Domain**: Ensure the address bar reads `https://thefatcat.fun` or `https://thefatcat.fun/belly`. Beware of lookalike domains using subtle character substitutions.
2. **Check Contract Addresses**: Compare contract targets with the [Verified Contracts Matrix]({% link contracts.md %}) schedule.
3. **No Signature for Free Grants**: The protocol never requires signing permit messages or approving unlimited spending for airdrops.
